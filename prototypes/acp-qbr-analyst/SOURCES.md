## How to read a scout file (30 seconds)
Each line = one claim + a `[CS:]` tag + a URL.
- `VERIFIED` / `HIGH` → trust it.
- `MEDIUM` → plausible, sanity-check.
- `LOW` / `[WOBBLY]` → directional; don't quote as fact.
- `UNKNOWN` / `[?]` → a named gap, not a finding.
- `FABRICATION RISK` → skip.

The tag tells you how hard to lean. That's the whole discipline — fluency ≠ accuracy.
