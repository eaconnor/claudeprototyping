- **AI Agents** — general-purpose AI agent platforms
- **AI Agent Control Planes** — orchestration and governance layers for AI agents

- **Security Detection & Response** — EDR, MDR, SOC, and SIEM tools
- **MSP Automation & PSA** — workflow automation, PSA, and ticketing for MSPs
- **AI for MSPs** — AI tools purpose-built for MSP operations

## Coverage Gap Analysis

| Gap Area | Notes |
|---|---|
| Identity & Access Management (IAM) | Okta, JumpCloud, Entra ID — MSPs manage identity but no pure-play IAM competitor tracked |
| Network Management | Auvik, Meraki — network monitoring/management for MSPs underrepresented |
| SaaS Management | Augmentt, Torii, BetterCloud — SaaS sprawl is a growing MSP problem |
| Vulnerability Management | Tenable, Rapid7, Action1 — patch and vuln mgmt distinct from RMM |
| Compliance & Reporting | Compliance Manager GRC, Drata, Vanta — compliance automation for MSPs |
| AI Observability / LLMOps | Arize, Langfuse, Weights & Biases — if NZO has AI ops features, this is white space |
