## What LOTL Means (Definition)

Attackers increasingly break in **without malware**. They use the same tools IT and administrators use every day:
- PowerShell
- Scripts  
- Admin utilities

**To traditional tools, this looks like normal work.**

### Characteristics of LOTL Attacks

- Use valid credentials  
- Use legitimate tools  
- Move slowly  

**Result:** Attacks now look like normal admin behavior. [CS: VERIFIED]

---

## Why Traditional Detection Fails

Humans and rules look for known bad behavior.

LOTL attacks succeed because they hide inside _normal patterns_.

**Humans and static rules are overwhelmed; signal exists only statistically.** [CS: HIGH]
