INC-2026-0834 · MDR · Black Team · Acme Bldg Supply · opened ~20 min ago

Lateral movement › credential access suspected

TA0008 Lateral Movement TA0006 Credential Access MITRE ATT&CK · sourced
How Alpha grouped these: per ADL-1839 Function Statement, Alpha correlates detections by shared user, host, source/destination, and time proximity. The twelve alerts in this incident share one user (user.acme@corp), two hosts, and fall inside a single working window. [R: ADL-1839 §Function Statement]
What happened
user.acme@corp authenticated from an unfamiliar ASN, then within the same session a privilege-escalation pattern was observed on host-east-04 and a Defender malicious-binary detection fired on host-east-09. The events share user, host lineage, and a contiguous time window. [A] — synthetic incident for prototype
Recommended response
Confirm whether user.acme@corp is a known traveller (HR / calendar). Pull the Defender quarantine report for host-east-09. If geography is unexpected, recommend session termination and an MFA challenge before unlock. [A] — recommended actions, not auto-executed by Alpha v0.9
Next steps
Escalate to Tier-2 with the consolidated incident if any of the above does not resolve cleanly. Tier-2 receives one ticket with the narrative, MITRE mapping, and the underlying twelve detections attached.
