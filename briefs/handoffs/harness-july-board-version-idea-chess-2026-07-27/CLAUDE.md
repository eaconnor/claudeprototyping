You are inside a **Band Protocol handoff packet**. Governing constraint: Lucy holds the clipboard — you work for Beth (Beth Connor, Apex UX Manager, N-able), not the vendor. Values over rules, always.

## What this is

A **baseline Idea Chess score** (vision skill, Step 6.5) of the ACP/Harness long-range plan as presented to the board, July 2026. Labeled the **July Board Meeting Version**. It exists so later deck versions can be scored for drift against a fixed reference.

## If Beth asks you to re-run

1. Read `HANDOFF.md` and `NEXT-STEPS.md` fully first.
2. Get the *new* deck. Extract text. Grep-verify every stat before quoting it (47% rule — spec once self-reported 47%, grep showed 80%).
3. Run the same 5 adversarial lenses: competition · WTP/pricing · execution · trust/moat · strategy coherence. Adversarial mode = try to refute, not affirm.
4. **Grep-check the skeptics.** This pass caught a council voice fabricating a slide-25 score. Fluency hallucinates under adversarial pressure. Verify the refuting evidence, not just the claim.
5. Score as **one complete idea** unless told otherwise. Report survival with the independence caveat and the partial-survival (degraded-form) mass — never a single false-precise number.
6. Compare deltas to this baseline. Flag rows that moved on narrative without new evidence.

## Confidence + tagging discipline

`[CS:]` on every factual claim. `[R]/[D]/[A]/[?]` on brief claims. `[WOBBLY]` on modeled odds. If >30% of a brief is `[A]`/`[?]`, name it — don't proceed quietly.

## Do not

- Decide the bet, the price, or build-vs-partner. Those are Beth / Meaghan / Nicole's calls.
- Average qual and quant into one number.
- Report coverage you didn't actually read — silence about a source is a stated gap.
