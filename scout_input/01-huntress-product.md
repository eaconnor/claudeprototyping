## Managed SIEM feature detail
- **Smart Filtering** — proprietary engine "identifies events that matter and stores only those"; avoids "data hoarding"/"log-heavy approaches"; reduces noise, storage cost, false positives. [CS: HIGH]
- **24/7 AI-Assisted, human-led SOC** — writes/tunes detections, triages, investigates, delivers incident reports. [CS: HIGH]
- **Log sources** — Windows Event Logs, syslog (firewalls/network), M365/Entra ID/Duo, AWS CloudTrail, DNS security; EDR integrations named: CrowdStrike, SentinelOne. [CS: HIGH]
- **Retention** — up to 7 years; encrypted in transit/at rest. Standard 1 month active / 12 months cold; rehydration first 500GB/yr free, then $1/GB. [CS: MEDIUM — support-doc reported]
- **Compliance frameworks** — SOC 2, HIPAA, PCI DSS, CMMC, GLBA, SOX. [CS: MEDIUM]
- **Pricing** — per data source (NOT per GB / log volume). Pooled allocation, flat-rate, "no surprise billing." Published $4.00/data source/mo at 50–99 tier; community/MSP-reported $1.25–$2.00. [CS: MEDIUM]
- "don't need an in-house SIEM engineer or standalone SOC to benefit." [CS: HIGH]
