## What is this?

The Band Protocol prototyping skill turns rough ideas into working HTML prototypes with research, specs, and routing guidance.

**One command. Full pipeline.**

When you type `/prototype [your idea]`, Claude automatically:
- Pulls source documents and research
- Writes a structured brief with evidence tags
- Reviews the spec before building
- Creates working HTML you can test in a browser
- Reviews what was built
- Packages everything for handoff

You get a complete prototype with design system, routing cards for your team, and honest gaps named.
