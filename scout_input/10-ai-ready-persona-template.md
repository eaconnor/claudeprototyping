## Core Problem
"Most personas die in Google Drive... Static personas can't influence AI generators, can't persist across flows."

Traditional personas: demographics + narrative storytelling → static PDFs
AI-ready personas: structured data schemas → machine-readable constraints that persist across multi-screen generation workflows

## Five Elements Required in AI-Ready Personas (not in traditional)
1. Information Density Metrics — explicit cognitive load tolerance levels → dictate progressive disclosure vs. dense layouts
2. Interaction Modality — how users interact (touch-first, keyboard-dominant, screen-reader dependent)
3. Behavioral Constraints — friction triggers, scanning patterns, task frequency → map to interface rules
4. JTBD Sequencing — structured as: trigger → task → checkpoint → completion (not just motivations)
5. LLM Appendix — machine-readable guardrails injected into prompts to prevent design drift across screens

## Key Claim
"Personas must transform from storytelling artifacts into active generation constraints that enforce consistent interface logic throughout entire journeys."
