## The pattern in one paragraph

Single prototype with T1/T2/T3 toggle. T1 shows Bradley scoring rail (risk score, 44-voice council, reasoning). T2 shows PM Action Dashboard (decision cards, hotspots). T3 shows Engineering + Design QA (handoff specs, checklists). Each tier serves different audience, non-cumulative. Validated with Alpha RACE test case 2026-05-28.
