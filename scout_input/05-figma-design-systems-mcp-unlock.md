## Core Framing
Flywheel: robust design systems → better AI output → improved AI/DS support → stronger design systems

## Key Quote
"Asking an AI agent to generate code without design system context is like asking a new engineer to start shipping code before onboarding."

## What Makes Design Systems AI-Readable (per Figma)
- Style and variable usage information
- Variable code syntax mappings
- Code Connect integrations
- Component libraries and naming conventions
- Design tokens with code implementations

## Statistics (methodology unverified)
- 68% of developers use AI to write code
- Only 32% of designers and developers trust the output
- Trust gap attributed to context deficiency

## What Fails
Generic prompting without system-level guidance → "generic UIs cobbled together from the same pool of AI-generated parts"

## New Capability
MCP server can generate automated design system rules — "a system-level guide for the agent, reducing ambiguity and ensuring generated code adheres to your team's standards."
