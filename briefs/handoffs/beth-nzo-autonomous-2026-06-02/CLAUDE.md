## What "Tier 1 Concept" Means

This prototype is **NOT** validated for stakeholder review. It tests:
- Can the Band Protocol pipeline generate a coherent prototype from a thin brief?
- Does the domain model hold together?
- Are the failure modes visible in seed data?

This prototype does **NOT** test:
- Whether MSPs need autonomous task execution
- Which tasks MSPs would trust N-zo to execute
- Whether N-central/N-sight APIs support rollback
- What compliance constraints apply

**Use for:** Pipeline stress-test, domain model review, internal design critique.  
**Do not use for:** Customer demos, stakeholder validation, roadmap commitment.
