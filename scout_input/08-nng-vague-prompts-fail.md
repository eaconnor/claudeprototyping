## Core Finding
"A detailed prompt yielded quality results resembling what a human designer created, whereas a vague prompt generated inconsistent and unpredictable outcomes."

## Four Failure Patterns (Vague Prompts)
1. Unnecessary visual clutter — AI generates more elements than needed
2. Repeated design elements — same information displayed multiple times
3. Counterintuitive content flow — information presented illogically
4. Mismatched visual hierarchy — visual prominence contradicts content priority

"Frankenstein layouts" — designs randomly pieced together instead of thoughtfully structured.

## Five Prompting Strategies (What Works)
1. Precise visual keywords — name specific styles (neobrutalism, skeuomorphism) not generic ("modern")
2. Lightweight visual references — moodboards or design-system screenshots
3. Visual analysis with AI — use ChatGPT to extract design characteristics for prompt formulation
4. Mock data — realistic sample content
5. Code snippets — attach component code directly; "the more direct the context you provide, the less interpretation the system needs to make"

## Key Limitation
"Good design decisions can't be automated" — strategic thinking, tradeoffs, and informed choices remain irreplaceably human.
