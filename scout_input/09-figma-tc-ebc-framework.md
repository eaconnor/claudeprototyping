## TC-EBC Framework
- Task — what you're building
- Context — why and for whom
- Elements — specific UI/component requirements
- Behavior — how the system should function
- Constraints — guardrails and limitations

## Core Principles
- "The more polite you are to a model, the more ambiguity you introduce." Models require clean instructions, not empathy.
- Like culinary mise en place: deliberate setup before execution
- Structure creates precision; vague prompts produce mediocre results

## What Makes Prompts Fail
- Unnecessary pleasantries and hedging language ("maybe," "just," "please")
- Buried tasks within rambling context
- Ambiguous behavioral expectations
- Missing guardrails or constraints

## What Makes Prompts Succeed
- Scannable, modular structure
- Explicit element and behavior definitions
- Constraints that prevent drift
- Context-engineered inputs: relevant Figma frames, design systems, PRDs
- Model selection matched to task type
