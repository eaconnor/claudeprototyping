# N-zo FAQs: Capabilities, Limitations, Data & Trust

**Source:** https://documentation.n-able.com/N-zo/userguide/Content/N-zo/n-zo-faqs.htm  
**Retrieved:** 2026-06-02  
**Confidence:** [CS: VERIFIED] — Official product documentation

## Capabilities

**Query ability:** Users can ask N-zo questions and receive responses within the platform

**Conversation history:** Full chat history accessible, organized by date with search functionality

## Limitations

**No autonomous actions:** [CS: VERIFIED]  
"N-zo does not perform remediation actions. It does not make changes to devices, systems, or configurations without human oversight and approval."

**Monthly credit limit:** 100 credits per technician that resets at the start of each calendar month

**Account-level only:** Currently unavailable on a per-user basis; enabled for entire accounts

**Optional use:** While visible to all users, engaging with N-zo is voluntary

## Data & Trust/Safety

**No external training:** "Your data is never used to train public or external large language models"

**Tenant isolation:** Data remains private to your organization and isn't shared across customers

**Storage duration:** Chat history retained "for 90 days up to one year" in AWS Bedrock

**Third-party restrictions:** "N-zo inputs and outputs are not shared with third parties"

**Feedback usage:** Thumbs up/down ratings accessed only by the N-zo team for improvement

## Access Control

Requires specific role permissions:
- "View AI" (N-sight) or "Read Only" (N-central) to use N-zo
- "Manage AI" permissions enable configuration but not usage
