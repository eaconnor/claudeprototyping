# Source: GeneyMAP — Designing GenAI-empowered User Journey Mapping Tool
SOURCE_URL: https://dl.acm.org/doi/10.1145/3706599.3720075
VENUE: CHI 2025 Extended Abstracts
TYPE: Peer-reviewed academic
CS_BASE: HIGH — peer-reviewed CHI venue

## Core Approach
Chain-of-thought approaches integrated with journey mapping principles. JM terminologies translated into LLM prompts:
- Scenario
- Phases
- Touchpoints
- Actions
- Emotion
- Pain points
- Opportunities

## Key Finding
To mitigate randomness in AI-generated journey content, output formats for each step were standardized, "establishing a tightly coupled relationship between steps."

## Implication
Formalized JM terminologies as structured prompt inputs reduces AI output variance in journey generation tasks.
