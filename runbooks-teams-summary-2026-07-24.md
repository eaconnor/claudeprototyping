**The big shift 🧭**
We walked in asking *"what runbooks should the agent build?"* We walked out asking *"what if ACP is an orchestrated business-coaching system that happens to generate runbooks?"* The runbook is not the product — **the guided journey is.** The control plane should own the lifecycle (discover → diagnose → build → review → test → maintain), not the document.

**Five things worth knowing 👇**

1. **A generic runbook is only the seed.** A ransomware playbook for "a business" is useless; it has to become a runbook for *this* environment and *these* assets (the pharmacy cabinet, the line-of-business server). Mission-critical assets get their own. Architecture ≈ *canonical pattern → client context → asset context → runbook.*

2. **"What good looks like" needs to be defined, not vibed.** Agents should build to a **golden schema** with validation and scoring — not free-form output. Stefanie's EBR template is a literal example of one of these schemas.

3. **Runbooks are business workflows, not IT tasks.** "You're an MSP, not an MITSP." The real value spans EBRs, risk registers, disaster recovery, compliance evidence, business continuity — not just the tech.

4. **The "QBR automation" ask was misread.** MSPs asking for QBR automation are asking from a *technical* lens. A good EBR isn't a backward-looking report — it's a forward-looking exec conversation. **Don't build "look at all the work we did."** Build the thing that surfaces gaps / risks / opportunities → pipeline. (Stefanie is sending her template + webinar.)

5. **The uncomfortable one: data alone isn't the moat.** Lewis: competitors have the same data access; "the data moat is short-lived." The durable advantage is the **workflow, orchestration, and encoded expertise** — the coached journey. Worth a real conversation, because it presses on our current framing.

**Where the team voted to start 🚀**
Golden starter set: incident response involving law enforcement (FBI) · disaster recovery + RTO testing · EBR · tabletop exercise. Ransomware is the universal front door.
