**SOAR / Security Automation**
- **SOAR** = Security Orchestration, Automation, Response [CS: HIGH]
- **SOAR playbooks** = fully executable automation within platform with conditional logic, API integrations [CS: HIGH]
- **Key benefits:** MTTR reduction from hours → minutes; fewer false positives via enrichment/correlation; one analyst can manage hundreds of alerts/day [CS: MEDIUM]
- **2025–2026 evolution:** LLM-optimized workflows replacing rigid no-code playbooks; AI-generated code for flexibility/scale [CS: MEDIUM — emerging trend, not widespread]

- **LOTL attacks:** Abuse native tools/processes (LOLBins) to blend with normal activity, evade signature-based detection [CS: HIGH]
- ConnectWise 2026 MSP Threat Report: Modern attackers abuse **trusted identities, legitimate system tools, existing access paths** vs custom malware [CS: HIGH]
- Detection requires **behavioral analytics (UEBA)** to spot anomalies in usage patterns/timing [CS: HIGH]
- Real-time monitoring + automated containment = isolate systems or kill malicious sessions autonomously [CS: MEDIUM]
