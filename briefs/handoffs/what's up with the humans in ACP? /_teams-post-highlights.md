📂 **ACP analysis — what we found**

Sharing highlights from the dive on Nicole's ACP V1. Full package: `briefs/handoffs/what's up with the humans in ACP?/`

**Top 5 MSP problems (ranked by impact × urgency):**

1. **False-positive alert burden** — 46% of alerts are false positives. ~960 alerts/day per MSP. Recovery work that doesn't recover anything.
2. **Technician burnout** — 75% of MSPs hit alert fatigue monthly. 100% of MSPs managing 1,000+ clients hit it daily.
3. **Tool sprawl** — 89% struggle with tool integration. Only 11% report seamless integration across their stack.
4. **Staffing & expertise gap** — 40%+ of MSPs can't find candidates with required skills. AI skill is the #1 ask.
5. **License & cost reconciliation** — "ninety percent of MSP hands would go up" (Aaron B.). Active license counts never equal billed.

**Headline on how ACP addresses these:**

- **Tool sprawl** → ACP *is* the integration layer. AI Coworkers compose vendor Experts + customer runbooks via MCP. The control plane, not the products.
- **Alert fatigue** → Alert Flood Suppression Coworker + Deterministic Substitution Engine. AI reasons; scripts execute when deterministic; tokens stop burning at the handoff.
- **Burnout & expertise gap** → Risk-classified runbooks let juniors handle more safely. Senior techs shift from clicking-through to design + oversight.
- **Margin pressure / per-device pricing** → 7-layer monetization model (platform + execution + Experts + marketplace + tool transactions + LLM passthrough + outcome). Value Ledger proves outcomes to the end customer.

**The big reframe:** ACP isn't "AI triage." It's an **MSP operating system** — N-able's products (UEM, Cove, Adlumin) become invisible infrastructure underneath a Shopify-style marketplace.
