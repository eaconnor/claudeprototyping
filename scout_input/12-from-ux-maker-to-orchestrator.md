## Core Claim
"The future of UX is not artifact creation at a higher speed. It is AI system orchestration."

## Role Transformation
- From control to uncertainty management
- From deterministic to probabilistic thinking
- Interface patterns shift from validation/error prevention → confidence gradients and reversibility

## Design System Claim
"Design systems are evolving from consistency libraries into machine-readable constraint engines." Semantic naming, tokens, and accessibility rules must embed compliance directly — not post-generation cleanup.

## Machine Experience
APIs, headless architectures, and semantic structure are now core experience design because agents navigate these programmatically.

## Five New Designer Competencies
1. Define rubrics with measurable criteria
2. Build realistic test datasets
3. Instrument behavioral signals (correction rates, escalations)
4. Diagnose failure patterns systematically
5. Iterate based on production evidence
