## Single strongest finding
The context engineering literature (Sources 1, 2, 4, 8, 13) converges on one claim: structure quality outpredicts prompting technique. More instructions without structure degrades adherence. The Markdown-vs-JSON finding (Source 6, 7) adds the principle: language-carrying structure beats pure schema when the agent is an LLM — rationale and scope rules need prose, not JSON nesting.
